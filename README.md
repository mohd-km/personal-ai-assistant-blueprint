# Digital Brain Architecture

A simple, calm, playable web showcase of **Digital Brain Architecture** by Mohammed KM.

## What Is Inside

100% client-side, zero runtime tokens, zero emojis, zero personal data:

1. **Send a Command Through the Brain** — Four everyday commands animate a 4-step trace (Input -> Context Router -> Harness Selection -> Safety Approval Gate -> Outcome), pausing outward email sends for explicit approval.
2. **Break a Model** — Toggle Antigravity, Claude, and Codex on or off to watch the priority waterfall reroute with zero downtime and $0 extra API spend.
3. **Inside the Brain** — Interactive 5-folder explorer (`rules`, `memory cards`, `lessons learned`, `playbooks`, `execution trail`) showing why portable Markdown files beat locked-in chat silos.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Output is written to `dist/index.html` and `dist/assets/`.
