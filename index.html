Why flat-rate failover avoids surprise API bills

Because every assistant reads the exact same plain Markdown folder, switching from Antigravity to Claude or Codex requires zero migration or re-prompting. Staying on existing flat-rate plans guarantees extra metered API spend stays at $0 even during provider outages.
